Never forget an appointment, bill, or library book

Calendar reminders nudge you when something is coming up — no code, no new account needed. This guide covers two approaches: your calendar app’s built-in reminders, and a tiny local script (scripts/calendar_reminders.py) that reads a plain text reminders file on your own computer.

Option 1: Your calendar app (no code at all)

Google Calendar

  1. Open calendar.google.com and create an event (e.g. "Dentist appointment").
  2. Click Add notification and choose when to be reminded (10 minutes, 1 hour, 1 day, or custom).
  3. Set it to repeat if it’s recurring (weekly meds, monthly bill).
  4. Make sure notifications are on for the calendar.

Outlook Calendar

  1. Open the event and pick Remind me (when to be notified).
  2. For repeating items, set Repeat (daily, weekly, monthly).

Apple Calendar (Mac / iPhone)

  1. Open the event, then click alert and choose when to be reminded.
  2. Set Repeat for recurring events.

Option 2: The local reminders script

scripts/calendar_reminders.py reads a reminders.txt file you maintain and tells you what’s due today, coming up soon, or overdue — all on your own computer, no apps or accounts needed.

A sample reminders.txt:

# Reminder name | due date (YYYY-MM-DD) | message
Electric bill | 2026-11-05 | Pay the electric bill
Library books | 2026-11-10 | Return library books
Dentist | 2026-11-01 | Dentist appointment

Step 1: Create your reminders file

Create reminders.txt in your Documents folder with lines like the example above. Lines starting with # are comments.

Step 2: Run the check (dry run)

python3 scripts/calendar_reminders.py ~/Documents/reminders.txt

You’ll see what’s due today, upcoming within 7 days, and overdue — plus a mailto: link for each one.

Step 3: Send email for real (optional)

export SMTP_HOST=smtp.example.com
export SMTP_USER=you@example.com
export SMTP_PASS=your-app-password
export FROM_EMAIL=you@example.com
export TO_EMAIL=you@example.com
python3 scripts/calendar_reminders.py ~/Documents/reminders.txt --apply

No credentials are stored in this script or the repo. --apply sends nothing unless all SMTP variables are set.

Make it a habit

Pick a regular time — every morning with coffee, or every Sunday evening — and run the check or glance at your calendar. You can even set a repeating event called "Check reminders."

Privacy: All reminder data stays in reminders.txt on your computer. Nothing is uploaded. Do not commit reminders.txt — it’s ignored by .gitignore.
