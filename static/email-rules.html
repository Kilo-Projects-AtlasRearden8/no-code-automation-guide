Sort your inbox automatically — no code needed

Email rules (also called filters) sort incoming mail automatically. The rules live in your email provider and run on their servers, so they work even when your computer is off.

What email rules can do

  • File newsletters into a Reading folder so your inbox stays for people
  • Flag bills and receipts so you never miss a due date
  • Mark shopping receipts as read and archive them
  • Move automated alerts (banking, shipping, pharmacy) to their own folders
  • Keep spam-like senders out of your inbox without blocking them entirely
Privacy note: Email rules run inside your email account — your mail stays with your provider. Don’t create rules that forward your email to an outside address unless you trust that destination, and never paste your password into a “rule builder” on a random website.

Gmail (filters)

  1. Open Gmail in a browser and click the Show search options icon (the slider icon) inside the search bar.
  2. Fill in what you want to match — for example From: newsletter@, Subject: invoice, or Has the words: unsubscribe.
  3. Click Create filter, then choose what happens: apply a label (e.g. Reading, Bills, Receipts), skip the inbox, or mark as read.
  4. Check Also apply filter to matching conversations to clean up old mail too, then save.

To edit later: Gmail → Settings → See all settings → Filters and Blocked Addresses.

Outlook / Outlook.com / Microsoft 365

  1. Go to Settings → Mail → Rules and click Add new rule.
  2. Give it a name (e.g. "File newsletters").
  3. Add a condition (who it’s from, subject words, message words).
  4. Add an action (Move to, mark as, categorize).
  5. Save. To clean up old mail, check Run rule now.

Manage rules later at Settings → Mail → Rules. Rules run top to bottom.

Apple Mail (Mac)

  1. Mail → Settings → Rules → Add Rule.
  2. Set conditions (any/all of: from, subject, etc.) and actions (Move mailbox to, set color, etc.).
  3. Click OK, then choose whether to apply it to existing mail.

Troubleshooting: rule not running? Check it’s enabled and you’re looking at the right account. Old mail isn’t sorted? Most providers only apply new rules to new mail — look for an option to apply to existing conversations.
