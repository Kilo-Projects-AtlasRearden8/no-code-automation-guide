Connect two apps — without writing code

Want "when I get an email with an attachment, save it to a folder"? No-code connection services link two services so an event in one triggers an action in the other:

  • Trigger: an email arrives with an attachment
  • Action: save the attachment to your Documents folder

General steps

  1. Sign up with the account you want to connect.
  2. Click Create / Make a zap / Create applet.
  3. Choose the trigger app and event (e.g. Gmail → New attachment).
  4. Connect your account (sign in when prompted).
  5. Choose the action app and event (e.g. Google Drive → Upload file).
  6. Map the fields (e.g. attachment → file, subject → file name).
  7. Name it, turn it on, and test it once before relying on it.
Privacy-first rule: never connect accounts that hold health, financial, or identity data unless you’ve read the service’s privacy policy. Start with low-stakes data, use the free tier first, and turn connections off when you’re done with them.

Local-first option: the folder watcher

scripts/folder_watcher.py watches a folder on your computer and notes whenever a new file appears — a private, local-only applet. It runs entirely on your machine, uploads nothing, and needs no account.

# Preview: see what it would do, without writing anything
python3 scripts/folder_watcher.py ~/Downloads

# For real: log new files to connections.log
python3 scripts/folder_watcher.py ~/Downloads --apply

With --apply, each new file is noted in connections.log (in the folder you run the script from) with the file name and time. It never moves, renames, or uploads anything. Press Ctrl-C to stop.

Safety: connection services can read, create, and delete data in your connected accounts. Review the permissions before you authorize, and remove connections you no longer use.
