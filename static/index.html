Welcome

Automate everyday tasks without writing code: email rules, file organization, calendar reminders, and simple app connections — using tools you already have, plus tiny scripts you can read end to end.

No programming experience needed. If you can copy and paste, you can use this manual. Plain English, step by step, never condescending.

What’s inside
