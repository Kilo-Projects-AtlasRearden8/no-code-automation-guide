Sort a messy folder by file type

Got a messy Downloads folder? scripts/organize_files.py looks at every file in a folder and moves it into a subfolder named after its type:

  • Documents/ — .pdf, .doc, .docx, .txt, .csv, .xlsx, .pptx, .rtf, .odt
  • Images/ — .jpg, .jpeg, .png, .gif, .webp, .bmp, .svg
  • Audio/ — .mp3, .wav, .m4a, .ogg, .flac
  • Video/ — .mp4, .mov, .avi, .mkv, .wmv
  • Archives/ — .zip, .rar, .7z, .tar, .gz, .bz2
  • Installers/ — .exe, .dmg, .pkg, .msi
  • Other/ — anything that doesn’t match the above

Files without extensions (and folders already in the folder) are left alone. If a file with the same name already exists, the script renames it (file-1.pdf) instead of overwriting.

Step 1: Make a test copy

cp -r ~/Downloads ~/Downloads-Test

Step 2: Preview first (dry run)

python3 scripts/organize_files.py ~/Downloads-Test

This prints what it would move without touching anything. Review the list carefully.

Step 3: Organize for real

python3 scripts/organize_files.py ~/Downloads-Test --apply

Step 4: Check the results

Open the folder and confirm the files landed in the right folders. Only run it on your real ~/Downloads once you’re confident.

Customize the script

See scripts/organize_files.py. It’s short and every line is explained. Want a folder for spreadsheets? Add .xlsx to the Documents group — it’s your script, edit it.

Safety reminder: This script moves files in place on the folder you point it at. Always test on a copy first. Your originals stay untouched until you’re sure.
