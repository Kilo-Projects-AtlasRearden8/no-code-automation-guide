# No-Code Automation for Beginners

Automate everyday tasks without writing code: email rules, file organization,
calendar reminders, and simple app connections — using tools you already have,
plus tiny, auditable scripts you can read end to end. Test on copies, never
move originals. Everything stays on your computer unless you choose otherwise.

## What's inside

- `docs/` — beginner manuals in Markdown (read them here, or in the static HTML
  site under `static/`).
- `scripts/` — tiny, auditable Python scripts (standard library only). Each one
  defaults to a non-destructive preview and never uploads your data anywhere.
- `static/` — a fully static HTML site mirroring the docs, no build step, no
  server needed.
- `static/planner.html` — a printable weekly automation planner you can print
  and fill in by hand.
- `tests/` — small tests that prove the scripts behave safely.

## How to use this manual

1. **Read the safety page first** (`docs/safety.md`). The golden rule: test on
   copies, never move originals.
2. Pick a task (email rules, organizing files, calendar reminders, app
   connections) and read its guide in `docs/`.
3. Follow the step-by-step instructions. Where a script is involved, run it on
   a test folder first, then decide whether to use it on your real files.
4. Print `static/planner.html` and use it to plan which automations to set up
   this week.
